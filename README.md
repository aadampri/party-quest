## What is this?

Party Quest provides a reusable structure for children's party games. Instead of disconnected mini-games, it connects them through a story arc where each game advances a shared goal (puzzle, map, keys) leading to a group finale.

**Key features:**
- Scalable from 2 to 9 players
- Printable HTML game plans with live-editable tables
- Game selector (pick which games to include)
- Multiple complexity levels (ages 3–12)
- Theme-independent game catalog
- Craft templates at 1:1 print scale

## Quick Start
