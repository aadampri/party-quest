Party Quest

Ein Framework für strukturierte Kinder-Partyspiele mit einer Quest-Erzählstruktur.

So funktioniert's

  1. Thema wählen.
  2. Spieleranzahl festlegen.
  3. Spiele aus dem Katalog wählen.
  4. Spielplan drucken.
  5. Party durchführen.
