# Katzen & Mäuse — Schatzsuche

Ein komplettes Party-Quest-Beispiel für 2–9 Kinder (5–7 Jahre).

## Thema

Der Hauskater **Monsieur Moustache** ist im Urlaub. Die Mäuse (Kinder) müssen seinen versteckten Käse-Schatz finden, indem sie seine Fallen (Spiele) überwinden.

## Dateien

- **[spielplan.html](spielplan.html)** — Druckbarer Spielplan mit interaktivem UI
- **[schlaeger-vorlage.html](schlaeger-vorlage.html)** — 1:1 Bastelvorlage für Katzen-Tischtennisschläger
- **[design.md](design.md)** — Design-Notizen und Varianten

## Merkmale

- 6 Hauptspiele + 2 Ersatzspiele
- Komplexitätsstufe: Mittel (Puzzleteile)
- Käse-Symbole als Sticker (7 Sorten)
- Dynamische Spieleranzahl (2–9)
- Spielauswahl per Klick
- Druck-optimiert für A4
