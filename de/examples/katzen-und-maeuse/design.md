# Treasure Hunt: The Cat's Away

## Theme
Cats & Mice — the house cat is on vacation, mice hunt for the hidden cheese.

## Story Arc

**Opening:** A letter from "Monsieur Moustache" (stuffed cat in a suitcase):

> "Dear mice — I've hidden the BEST cheese in the house before I left. You'll NEVER find it! I ripped up the map and scattered the pieces. And I set traps (challenges) to guard each one. Good luck, you tiny furballs! — Monsieur Moustache"

Deliver with a paw print stamp.

**Framing:** Each game station is a "cat trap" to outsmart.

## Core Mechanics (proven design)

**Core loop (same at all levels):** Win game → winner picks recipient → recipient claims something.

### Complexity Levels

| Level | Map | Binding | Best for |
|-------|-----|---------|----------|
| **Simple** | Pre-assembled, visible from start | Recipient puts sticker on a spot on the map | Ages 3–5 |
| **Medium** | Cut into pieces, earned through games | Recipient marks their piece with symbol | Ages 5–7 |
| **Advanced** | Pieces earned + assembled reveals hidden location | Symbol on piece matches symbol on treasure | Ages 7+ |

### This time: Medium level

1. N-1 games, last piece given to last child
2. Winner of each game picks who receives the next puzzle piece
3. Recipient marks piece with their **cheese symbol** (not color — thematic!)
4. All pieces assembled together → reveals treasure location
5. Group hunts together → cheese-symbol-matched individual treasures at the spot

## Cheese Symbols (one per child)

- Swiss (holes) / Gouda (round) / Brie (wedge) / Cheddar (orange block) / Fondue (pot) / Butter (square)
- Draw as simple icons on stickers + matching on treasure wrapping

## Game Ideas ("Cat Traps")

**Final order (narrative + energy alternation):**

### 0. Build Your Cat Disguise (Craft + Balance) — Base/table
**Framing:** "Build your cat disguise! If you look like a cat, the traps won't trigger. Now prove you can move like one — carry the cheese without dropping it!"
- Craft: Assemble DIY table tennis racket — cup as nose/handle, cardboard around as paddle face, decorate as cat face
- Game: Balance table tennis ball on cat racket, walk around pillar and back
- Drop = restart or time penalty
- Fastest time wins
- **Type:** Craft + Physical / Balance
- **Energy:** Calm start

### 1. Backwards Escape — Pillar Run — Open space
**Framing:** "We're at the entrance! But look — there's a mirror alarm. It only sees mice running FORWARD. If we go backwards, we're invisible! Who's the fastest backwards-mouse?"
- Run/walk backwards from start → around a pillar/tree/cone → back to start
- Fastest time wins
- Simple, high energy, funny to watch
- **Type:** Physical / Speed
- **Energy:** High

### 2. The Cat's Code — Dice Guess — Anywhere
**Framing:** "We're inside! But the next door is locked with a number code. The code changes every time! Guess the secret number — then we roll to see who cracked it!"
- Each player guesses a sum (3–18)
- Throw 3 dice
- Closest guess wins (tie = re-roll or shared win)
- Multiple rounds possible
- **Type:** Mental / Luck
- **Energy:** Low (recovery)

### 3. Fire Trap — Water Pistol Sponge Shoot — Open space
**Framing:** "Oh no — the cat set a FIRE TRAP in the kitchen! We need to put out the flames before the map pieces burn! Grab your water pistols — the best firefighter wins!"
- One sponge per player, hung on clothesline at chest height (big car-wash sponges)
- Kitchen scale to weigh before/after
- All pistols same model, filled equally
- Fixed distance (tape line), fixed time (15 seconds, loud timer)
- Heaviest sponge wins
- **Type:** Aim / Physical
- **Energy:** Medium

### 4. Guard Dog's Snack — Mud Kitchen Weighing — Playground
**Framing:** "We made it to the backyard — but the guard dog is blocking the way! He'll only let us pass if we bring him his favorite snack — but it has to be EXACTLY the right weight. Mix your ingredients carefully!"
- Use mud kitchen at playground + kitchen scale (already brought for sponge game)
- Announce target weight (e.g., 500g)
- Each player scoops 3 ingredients (sand, pebbles, leaves etc.) into a container
- Weigh → closest to target wins
- No adjusting after placing on scale — commit to your mix
- **Type:** Mental (estimation) / Sensory
- **Energy:** Low/medium

### 5. Rooftop Escape — Playground Circuit — Playground
**Framing:** "ALARM! Monsieur Moustache is coming back early from vacation! We have to escape across the rooftops NOW! Over the bars, down the slide, around the tower — RUN! The fastest mouse escapes with the last piece!"
- Circuit: slide down → run to monkey bars → cross (or skip underneath if too hard) → touch pillar → climb frame → ring bell/slap mark at top
- Timed individually, fastest wins
- Allow monkey bar bypass (run under) for kids who can't cross — small time penalty
- **Type:** Physical / Speed / Agility
- **Energy:** High (climax)

## Fallback Games

### F1. Cheese Shelf Trap — Racket Catch
**Framing:** *"A trap! The cat rigged the cheese shelf to collapse! Cheese balls are falling — catch them with your disguise before they hit the floor and trigger the alarm!"*
- Reuses cat racket from game 0
- Adult/helper tosses table tennis balls, player catches with racket
- Most catches in 10 attempts wins (or first to 5)
- **Type:** Physical / Coordination
- **Slots in for:** Any physical game

### F2. Glue Trap — Standing Long Jump
**Framing:** *"The cat poured glue across the hallway! Your feet are stuck together — jump as far as you can to clear the sticky zone!"*
- Both feet together, standing start
- Measure landing distance
- Furthest wins
- **Type:** Physical / Power
- **Slots in for:** Any physical game

## Treasure Map

Aerial photo of treasure location, cut into N pieces (one per child).

## Props

- Mouse ears (headband + felt) for each child
- Stuffed cat in a suitcase
- Letter with paw print
- Color stickers
- Treasure: yellow/cheese-colored wrapping, color-coded per child

## Variations to Consider

- Map could be hand-drawn with landmarks instead of photo
- "Blind assembly" — place face-down, flip for dramatic reveal
- Two-stage: map shows intermediate spot with second clue
