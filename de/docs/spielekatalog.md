# Spielekatalog

Ein wiederverwendbarer Katalog von Mini-Spieltypen. Jedes Spiel ist themenunabhängig — das Thema liefert nur die Story-Rahmung.

## Zeitspiele

### Balance-Rennen
- **Aufbau:** Objekt auf Schläger/Teller, Parcours mit Wendepunkt
- **Metrik:** Schnellste Zeit (Fallen = Neustart oder Zeitstrafe)
- **Material:** Schläger + Ball, Kurs-Markierungen
- **Energie:** 🟡 Mittel

### Rückwärts-Rennen
- **Aufbau:** Gerader Kurs, rückwärts laufen
- **Metrik:** Schnellste Zeit
- **Material:** Kurs-Markierungen
- **Energie:** 🔴 Hoch

### Hindernisparcours
- **Aufbau:** Multi-Stationen-Kurs (klettern, kriechen, laufen, rutschen)
- **Metrik:** Schnellste Zeit
- **Material:** Spielplatz-Geräte oder improvisierte Hindernisse
- **Energie:** 🔴 Hoch

## Genauigkeitsspiele

### Zahlenraten (Würfel)
- **Aufbau:** Jeder Spieler tippt eine Summe, Würfel werden geworfen
- **Metrik:** Nächster Tipp am tatsächlichen Wurf
- **Material:** 3 Würfel, Becher
- **Energie:** 🟢 Ruhig

### Gewichtsschätzung
- **Aufbau:** Spieler mischen Materialien um ein Zielgewicht zu treffen
- **Metrik:** Nächster am Ziel
- **Material:** Küchenwaage, Behälter, loses Material (Sand, Steine, Blätter)
- **Energie:** 🟡 Mittel

## Sammelspiele

### Schwamm tränken (Wasserpistole)
- **Aufbau:** Schwämme hängen an Leine, mit Wasserpistole bespritzen
- **Metrik:** Schwerster Schwamm (vorher/nachher wiegen)
- **Material:** Wasserpistolen (gleich), Schwämme, Wäscheleine, Küchenwaage
- **Energie:** 🟡 Mittel

### Fangen
- **Aufbau:** Bälle werden geworfen, mit Schläger/Becher/Händen fangen
- **Metrik:** Meiste Fänge aus N Versuchen
- **Material:** Leichte Bälle, Fanggerät
- **Energie:** 🟡 Mittel

## Distanzspiele

### Standweitsprung
- **Aufbau:** Aus dem Stand springen
- **Metrik:** Weiteste Landung
- **Material:** Maßband, Bodenmarkierungen
- **Energie:** 🔴 Hoch

## Kreativspiele

### Basteln + Benutzen
- **Aufbau:** Etwas bauen (Schläger, Hut, Schild), dann im Mini-Spiel benutzen
- **Metrik:** Zeit bei Benutzung des gebastelten Gegenstands
- **Material:** Bastelmaterial (Karton, Becher, Klebeband, Stifte)
- **Energie:** 🟢 Ruhig (Basteln) → 🟡 Mittel (Benutzen)

## Spiele kombinieren

### Empfehlung für 7 Spieler (6 Spiele):

1. 🟢 Basteln + Balance (Schläger bauen, dann Balance-Rennen)
2. 🟡 Rückwärts-Rennen
3. 🟢 Würfelraten
4. 🟡 Schwamm tränken
5. 🟡 Gewichtsschätzung
6. 🔴 Hindernisparcours

### Empfehlung für 5 Spieler (4 Spiele):

1. 🟢 Basteln + Balance
2. 🟡 Schwamm tränken
3. 🟢 Würfelraten
4. 🔴 Hindernisparcours
