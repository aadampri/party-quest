# Game Catalog

A reusable catalog of mini-game types. Each game is theme-independent — the theme provides only the story framing.

## Timed Games

### Balance Race
- **Setup:** Object on paddle/plate, course with turn-around point
- **Metric:** Fastest time (drop = restart or penalty)
- **Materials:** Paddle + ball, markers for course
- **Energy:** 🟡 Medium

### Backward Race
- **Setup:** Straight course, run backward
- **Metric:** Fastest time
- **Materials:** Course markers
- **Energy:** 🔴 High

### Obstacle Course
- **Setup:** Multi-station course (climb, crawl, run, slide)
- **Metric:** Fastest time
- **Materials:** Playground equipment or improvised obstacles
- **Energy:** 🔴 High

## Accuracy Games

### Number Guessing (Dice)
- **Setup:** Each player guesses a sum, dice are rolled
- **Metric:** Closest guess to actual roll
- **Materials:** 3 dice, cup
- **Energy:** 🟢 Calm

### Weight Guessing
- **Setup:** Players assemble a mix to hit a target weight
- **Metric:** Closest to target
- **Materials:** Kitchen scale, containers, loose materials (sand, stones, leaves)
- **Energy:** 🟡 Medium

## Accumulation Games

### Sponge Soaking (Water Pistol)
- **Setup:** Sponges hanging on a line, shoot with water pistol
- **Metric:** Heaviest sponge (weigh before/after)
- **Materials:** Water pistols (equal), sponges, clothesline, kitchen scale
- **Energy:** 🟡 Medium

### Catching
- **Setup:** Balls thrown at player, catch with paddle/cup/hands
- **Metric:** Most catches out of N attempts
- **Materials:** Lightweight balls, catching device
- **Energy:** 🟡 Medium

## Distance Games

### Standing Jump
- **Setup:** Jump from standing position
- **Metric:** Farthest landing
- **Materials:** Measuring tape, ground markers
- **Energy:** 🔴 High

## Creative Games

### Craft + Use
- **Setup:** Build something (racket, hat, shield), then use it in a mini-game
- **Metric:** Timed use of the crafted item
- **Materials:** Craft supplies (cardboard, cups, tape, markers)
- **Energy:** 🟢 Calm (craft) → 🟡 Medium (use)

## Combining Games

### Recommended for 7 players (6 games):

1. 🟢 Craft + Balance (build racket, then balance race)
2. 🟡 Backward Race
3. 🟢 Dice Guessing
4. 🟡 Sponge Soaking
5. 🟡 Weight Guessing
6. 🔴 Obstacle Course

### Recommended for 5 players (4 games):

1. 🟢 Craft + Balance
2. 🟡 Sponge Soaking
3. 🟢 Dice Guessing
4. 🔴 Obstacle Course
