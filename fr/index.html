Party Quest

Un framework pour des jeux de fête structurés pour enfants avec un arc narratif de quête.

Comment ça marche

  1. Choisir un thème.
  2. Définir le nombre de joueurs.
  3. Sélectionner des jeux dans le catalogue.
  4. Imprimer le plan de jeu.
  5. Animer la fête.
